# Sokak Kedisi Hayat Danışmanı

## Bu Nedir?

Bu, insanlık tarihinin en önemli teknolojik atılımıdır. Sokak kedilerinin binlerce yıllık bilgeliğini yapay zeka (yani rastgele seçim) ile birleştirerek size hayat tavsiyesi veren **gerçekten çalışan** bir program.

Neden sokak kedisi? Çünkü onlar:
- Hiçbir şey umursamaz
- Her şeyi görmüştür
- Balık isterler
- Ve sizin varoluşsal krizlerinize gülerler

## Nasıl Çalışır?

```bash
python kedi_danismani.py
```

Ya da soru sorarak:
```bash
python kedi_danismani.py "Neden her şey bu kadar pahalı?"
```

Kediniz düşünecek, esneyecek ve size hayatın gerçek anlamını (ya da "uyuyayım") anlatacak.
